# 小月立绘 · 即梦提示词包 v2

> 目标：解决 ① 跨表情人物一致性偏差 ② 跨表情人物大小不一致 ③ 新增二头身超 Q 版整套素材。
> 用法：先读「一、二」理解流程，再按「三」的模块拼装，或直接抄「四、五」的完整提示词。

---

## 一、两个老问题的成因与对策

### 问题 1：跨表情人物高矮胖瘦、脸大小有偏差

成因：每张图都是独立生成，模型对"三头身"的自由发挥每次不同；即梦同一段文字每次 rollout 的头身比、脸宽都会有 5–15% 漂移。

对策（三条同时用）：

1. **参考图锁角色**：base 定稿后，后续 6 张表情全部以 base 为参考图生成，参考维度选「人物/角色形象」（只锁长相、发型、服装），**不要**选「主体/画面全参考」（会把表情姿势也锁死，改不动表情）。参考强度建议 60–75%。
2. **提示词里加一致性指令**（模块 M5）：明确写"与参考图保持完全相同的头身比例、脸型、发型、服装和姿势，仅面部表情改变"。
3. **提示词正文逐字不动，只换表情词**：除【表情】一句外，其余部分（画风、角色、构图）在所有 7 张之间一个标点都不改。

### 问题 2：跨表情人物在画面里的大小差别大

成因：模型每次自由决定人物在画幅里的占比；你们后期统一裁边缩放到 384px 高，原始占比不同 → 缩放后人物实际大小不同。

对策：

1. **构图锁定句**（模块 M3）：把"人物身高占画面约 80%、头顶和脚底各留约 10% 空白、双脚并拢垂直站立"写死进提示词。模型对百分比类约束服从度较高，能把占比方差压到很小。
2. **同一批图用同一画幅比例**（建议 2:3 竖版），不要中途换比例。
3. **后期兜底**（现有流程已具备）：裁边时以"头顶→脚底"为锚点统一缩放，而不是以画布边缘为锚点。提示词做到位后，这步只需要微调。

## 二、即梦操作流程

### 方案 A：逐张生成（主流程，每张质量最高）

1. 新建会话，画幅选 **2:3 竖版**，模型选最新版（4.x），分辨率 2K。
2. 用「四」中对应形态的 **base 完整提示词** 生成，刷到一张满意的定稿。
   - 若当前版本有「透明背景/透明底」输出选项则勾选；没有就用纯白背景，沿用你们现有去背裁边流程。
3. 把定稿上传为**参考图**，参考维度选「人物/角色形象」，强度 60–75%。
4. 依次生成其余 6 个表情：提示词 = base 提示词，仅把【表情词】替换为模块 M4 中对应的一条，**其他一字不改**，并在开头加上 M5 一致性指令。
5. 每个形态重复 2–4。四个形态共 28 张。
6. 按「六、验收清单」检查，不合格的单个表情重刷（只重刷那一张，不动已定稿的）。

### 方案 B：一张多格表情设定图再切分（一致性最强，适合兜底）

一次生成"同一角色 7 个表情的设定图"，同一次生成内角色天然一致，后期按格子裁开。缺点是单格分辨率低、姿势容易雷同，适合做 Q 版表情包式素材，或当方案 A 怎么刷都不一致时的兜底。

提示词见「五、3」。

### M4 · 表情词（7 选 1，只换这句）

| 表情 | 提示词 |
|------|--------|
| base 自然 | 表情自然放松，嘴角微微上扬带浅笑，眼睛平视前方。 |
| happy 开心 | 表情非常开心，双眼弯成月牙笑眼，张嘴露齿大笑，脸颊泛红。 |
| angry 生气 | 表情生气，眉头紧皱倒竖，鼓起腮帮，嘴角下撇。 |
| surprised 惊讶 | 表情惊讶，眼睛瞪圆，瞳孔微缩，嘴巴张成O形。 |
| sleepy 困倦 | 表情困倦，眼皮半垂快要闭上，嘴巴微张打着哈欠，眼角挂一滴困泪。 |
| shy 害羞 | 表情害羞，视线向下躲闪，双颊大面积红晕，嘴巴抿成小小的ω形。 |
| smirk 坏笑 | 表情坏笑，单侧嘴角上扬，一只眼轻轻眯起，一侧眉毛微微挑起。 |

> 注意：表情词里**只写面部、不写动作**。一旦写"双手叉腰/举起手"这类动作词，姿势变化会破坏跨表情的身形一致性（Rive 里切换时会跳）。

### M5 · 一致性指令（表情差分时加在提示词最前面，base 不用加）

```
与参考图保持完全相同的角色：相同的头身比例、脸型、发型、发色、瞳色、服装、饰品和站立姿势，人物在画面中的位置和大小与参考图一致，仅面部表情发生改变。
```

## 六、验收清单（每张图生成后核对）

1. **头身比**：头高 ÷ 全身高，标准版 ≈ 1/3，Q版 ≈ 1/2，偏差 >10% 重刷。
2. **画面占比**：人物头顶→脚底 ÷ 画面高度 ≈ 80%，偏差 >5% 重刷（这是问题 2 的直接指标）。
3. **脸宽**：同一形态 7 张之间，脸最宽处像素偏差 >5% 重刷（问题 1 的直接指标）。
4. **识别标志齐全**：K2.6 月牙发夹+平板 K；K3 月牙发饰+星形胸针+小月球机器人；K3+ 耳机+红领结+全息屏；K3max 皇冠+法杖+月相光环。缺件或多件重刷。
5. **姿势不变**：7 张之间只有脸在变，手脚位置一致；出现抬手、叉腰、转身即重刷。
6. **命名入册**：沿用 `{形态}_{表情}.png` 规则，裁边去背后更新 `manifest.json`。
